# Weethet Tap

## How do I install these formulae?

`brew install weethet/tap/<formula>`

Or `brew tap weethet/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "weethet/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
